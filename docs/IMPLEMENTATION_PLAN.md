# 구현 계획

각 단계는 "브라우저에서 사용자가 직접 확인할 수 있는 결과"로 끝난다. 단계마다 브랜치 → 테스트 → 커밋 → main 병합.
상태 표시: ⬜ 미착수 · 🟨 진행 중 · ✅ 완료(테스트로 확인됨)

## 0단계. 저장소·문서 ✅
- GitHub 저장소, 요구사항 원문, 아키텍처·계획·결정 문서

## 1단계. 프로젝트 기본 환경 ✅
- Vite + React + TypeScript, ESLint, Vitest, Playwright, Recharts
- 3단 레이아웃 뼈대(왼쪽 패널 / 중앙 캔버스 / 오른쪽 통계), 한국어 라벨
- 빈 Web Worker 왕복 메시지 확인
- GitHub Actions: 타입 검사 + 단위 테스트 + 빌드
- **확인:** `npm run dev` → 브라우저에 3단 화면

## 2단계. 트랙 시스템 ✅
- 시드 PRNG, 하·중·상 생성기, 검증기, 체크포인트, 출발선, 출발 그리드용 직선 구간 보장
- 트랙 미리보기 렌더링, 다시 생성, 시드 표시·복사·입력
- **테스트:** 난이도별 시드 1000개 전부 검증 통과 / 같은 시드 → 같은 좌표 / 멀리 떨어진 구간 간 최소 거리
- **확인:** 브라우저에서 트랙을 여러 번 다시 생성해 보기
- 트랙 고정은 "주행 시작" 버튼에 연결했다 (실제 주행은 3단계). "새 판 시작"으로 고정을 푼다

## 3단계. 자동차 물리·렌더링 ✅
- 자전거 모델, OBB, 벽 충돌, 고정 dt 루프(워커), 일시정지·재개·배속
- 출발 그리드 5 × 10 = 50자리, 세대마다 무작위 배치 후 동시 출발 (기본 50대)
- 이 단계에서는 신경망 대신 **무작위 상수 조종**으로 차를 움직여 물리만 확인 (4단계에서 교체)
- **테스트:** 직진 시 벽 충돌 종료 / 차끼리 겹쳐도 영향 없음 / 배속별 동일 결과
- **확인:** 50대가 그리드에 줄지어 서 있다가 같이 출발해 벽에 부딪혀 멈추는 모습
- 결과: 단위 테스트(물리·충돌·동시 출발·독립성·1/10배속/건너뛰기 결과 동일·일시정지) + 브라우저 테스트(카운트다운, 일시정지·재개, 건너뛰기, 10배속과 건너뛰기의 최종 화면 픽셀 동일)

## 4단계. AI 주행 ✅
- 센서 5개, 신경망 5-6-2, 진행률, 체크포인트, 종료 조건 3종 + 안전 종료, 완주
- **테스트:** 역주행·결승선 왕복으로 완주 불가 / 헤어핀에서 진행률 점프 없음 / 출발 시 속도 0 은 브레이크 종료 아님
- **확인:** 무작위 신경망 차들이 각자 다르게 달리고 종료 사유가 표시됨
- 결과: 중심선 추종 운전자로 한 바퀴 → 정확히 완주 판정, 뒷줄 출발도 공정(완주 시간 차 1.5 s 이내), 역주행·결승선 왕복으로 완주 불가, 헤어핀 연속성, 브레이크/진행 없음/시간 제한 판정, 센서 격자 = 전수 검사 결과
- 최고 완주 기록 표시(`--:--.--` / 시간 / `완주 기록 없음`)도 함께 넣었다 (원래 8단계)

## 5단계. 유전 알고리즘 ✅
- 공식 순위, 적합도, 엘리트, 토너먼트 선택, 교차, 돌연변이, 세대 생성(중복 방지 토큰)
- 금색 챔피언 1대 표시 (오라는 9단계에서 꾸밈), 챔피언은 직전 1등의 출발 자리 그대로
- **테스트:** 엘리트 유전자 비트 단위 동일 / 챔피언 기록 = 직전 세대 1등 기록 / 금색 정확히 1대
- **확인:** 세대가 넘어가도 최고 진행률이 떨어지지 않음

## 6단계. 수동 부모 선택 ✅
- 클릭 토글, 드래그 사각형 추가 선택, 선택 수 표시, 선택 초기화, 결정완료(≥2대)
- **확인:** 종료 위치 그대로인 차들을 골라 다음 세대 생성
- 추가: 마우스를 올리면 번호·진행률·종료 사유 표시, "자동으로 부모 고르기" 버튼

## 7단계. 완전 자동 진화 ✅
- 자동 학습 시작/정지, 시간 예산 루프, 실제 배속 표시, 정지 후 일반 화면 즉시 복귀, 이어하기
- **테스트:** 정지 명령 후 새 세대 생성 0회 / 정지 → 재개 시 상태 동일
- **확인:** 수십 세대가 자동으로 돌아가는 동안 정지 버튼이 즉시 반응
- 결과: 5·6·7단계를 한 PR 로 구현 (세대 관리가 워커의 "실험" 하나로 묶여 있어 나누기 어려웠다). 브라우저에서 약 8초에 4세대 이상 자동 진행 확인

## 8단계. 기록·데이터 ✅
- 완주 기록 표시(`--:--.--` / 시간 / `완주 기록 없음`), 세대별 통계, 그래프, JSON 저장·불러오기, CSV
- **테스트:** 저장 → 불러오기 왕복 후 상태 동일 / 손상 파일은 거부하고 현재 상태 유지
- 결과: 주행 중·부모 선택 중·세대 경계 어디서든 정확한 상태로 저장(그 시점을 파일과 알림에 표시), 불러오면 일시정지 상태로 이어짐. 최고 유전자 JSON 저장 추가

## 9단계. 시각 효과 ✅
- 금색 오라·파티클, 고스트(3가지 대상), 종료 사유별 표시, UI 다듬기
- 결과: 금색 광원·도는 입자·뒤로 흩날리는 반짝임(종료하면 멈춤), 고스트(역대 최고 기본 / 이전 세대 / 특정 세대, 부모 선택 중 숨김), 종료 표시(✕ ■ ✓ ○)와 범례, 그래프 진행률/적합도 전환. 고스트를 켜든 끄든 결과가 같음을 브라우저 테스트로 확인

## 10단계. 종합 검증·발표 준비 ⬜
- Playwright 시나리오(수동 선택, 자동 학습 정지·복귀, 저장·불러오기), 성능 측정(100대), 시연용 저장 파일
