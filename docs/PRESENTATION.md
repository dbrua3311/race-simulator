# 발표 시연 가이드

원문 PART 21(발표용 시연 시나리오)을 실제 화면 조작으로 옮긴 것. 발표 전에 한 번 따라 해 보고, 학습이 잘 된 실험을 저장해 두는 것을 권장한다 (진화 결과는 매번 좋아진다는 보장이 없으므로).

## 준비

```bash
cd /mnt/extra/race-simulator
npm run dev        # http://localhost:5173
```

- 브라우저 창은 가로 1440 px 이상이 보기 좋다 (트랙 전체가 중앙에 들어간다).
- 발표 직전에 미리 학습시킨 실험 파일(`*.race.json`)을 준비해 두면 4~5번 대신 바로 불러와 보여 줄 수 있다.

## 알아 두면 좋은 점

- **1등 기준**: 완주하지 못해도 가장 멀리 간 차가 1등이다. 완주한 차끼리는 시간이 빠른 차.
- **금색 챔피언 = 엘리트 1대**: 교차·돌연변이 없이 1등 유전자를 그대로, 1등이 출발했던 자리에서 출발한다. 그래서 최고 진행률이 세대를 거듭해도 떨어지지 않는다.
- **고스트**는 기록을 다시 보여 줄 뿐 학습에 영향이 없다. "이전 세대 1등" 고스트는 챔피언과 정확히 겹친다(같은 주행).
- **건너뛰기**는 강제 종료가 아니라 같은 계산을 화면 없이 빨리 끝내는 것이다. 1배속·10배속·건너뛰기 결과가 같다.
- 학습이 막히면 "돌연변이 확률"을 올리거나(새로운 시도 증가), 수동으로 좋은 부모를 골라 준다.
